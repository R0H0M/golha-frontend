🌿 پورتال اختصاصی و هوشمند دهکده گل‌های کرمان (Dehkade Golha Portal)

پورتال جامع خدمات شهری، مسکونی و گردشگری «دهکده گل‌های کرمان»؛ توسعه‌داده‌شده با
آخرین استانداردهای فرانت‌اند وب، معماری مبتنی بر Next.js App Router و ارتباط
زنده با APIهای دیتابیس Django REST Framework (DRF).

این وب‌سایت از نظر تجربه کاربری (UX) و زیباشناختی بصری (UI) بر اساس الگوی رسمی
شهرداری سانتا مونیکا (santamonica.gov) پیاده‌سازی شده و تمرکز شدیدی بر روی فضای
خالی سفید (White-space)، مینی‌مالیسم، چیدمان‌های بنتو گرید (Bento Grid) و
منحنی‌های ارگانیک (Wavy S-Curves) دارد.

🛠️ استک فنی و ابزارها (Tech Stack)

  - فریم‌ورک اصلی: Next.js 16 (App Router با موتور Turbopack)
  - کتابخانه رابط کاربری: React 19 (معماری ترکیبی Server Components & Client
    Components)
  - زبان برنامه نویسی: TypeScript (Strict Type-Safety)
  - استایل‌دهی: Tailwind CSS v4 (پیکربندی CSS-First با دایرکتیو @theme و
    پشتیبانی کاملاً بومی از RTL)
  - انیمیشن‌ها و میکرواینتراکشن‌ها: Framer Motion & CSS Scroll-Snap
  - تایپوگرافی: فونت محلی فارسی Kook با رعایت استانداردهای دسترس‌پذیری وب (WCAG
    AA)
  - بهینه‌سازی تصاویر: Next.js <Image> با پشتیبانی از آی‌پی‌های محلی دیتابیس
    (dangerouslyAllowLocalIP) و آدرس‌دهی مطلق عکس‌های نسبی بک‌اند

🚀 ویژگی‌ها و صفحات اصلی پورتال

۱. صفحه اصلی (Home Page)

  - آلرت بنر اضطراری (Alert Banner): فراخوانی زنده آخرین خبر فوری از اندپوینت
    /api/v1/cms/announcements/latest/. در صورت عدم وجود بحران، بنر به طور کامل
    مخفی می‌ماند.
  - هدر رسمی ۶۴پیکسلی (h-16): شامل لوگوی رسمی، ۸ بخش ناوبری اصلی (با
    تفکیک‌کننده‌های سبز کله‌غازی) و پدینگ عریض lg:px-28.
  - بخش هیرو (Hero Section): لود تصویر محلی با بهینه‌سازی LCP، تایپوگرافی
    خوش‌آمدگویی و باکس جستجوی بیضی‌شکل مینی‌مال با سایه‌ی شناور.
  - پیرامون دهکده ما (Around Our City): گرید ۳ ستونه کارت‌ها با افکت لغزنده
    هاور، نمایش اسلایدر ۱ کارته در موبایل (CSS Scroll-Snap) و دکمه‌های ناوبری.
  - شناخت دهکده و آمارها (Village Introduction): بنتو گرید نامتقارن معرفی نگین
    کرمان، عکس هوایی و شمارنده‌ی عددی متحرک (<AnimatedCounter />) که با اسکرول
    کاربر به این بخش شروع به شمارش از صفر می‌کند.
  - مدیریت و شورا (Team Members): دایرکتوری مینی‌مال مدیران به سبک شهرداری با
    پس‌زمینه خاکستری #f4f8fb و موج مشکی اتصال به فوتر.
  - فوتر مشکی سراسری (Footer): فوتر فشرده مشکی (#121212) در ۵ ردیف متوازن.

۲. بخش اخبار و مقالات (CMS)

  - آرشیو اخبار (/cms): اسلایدر خودکار ۵ ثانیه‌ای مطالب پرطرفدار در بالا (با
    قابلیت توقف خودکار هنگام هاور موس)، نوار فیلتر افقی دسته‌بندی‌ها (توسعه،
    طراحی، کسب و کار، مشاوره، اخبار دهکده، اطلاعیه‌ها) و گرید ۳ ستونه مقالات.
  - تک صفحه مقاله (/cms/[slug]): مطالعه متن در اندازه فونت بزرگ و خوانا، نمایش
    دیدگاه‌های تاییدشده کاربران (GET /api/v1/cms/articles/{slug}/comments/) و
    فرم تعاملی ارسال دیدگاه جدید (POST).

۳. بخش اطلاعیه‌ها (Announcements)

  - آرشیو اطلاعیه‌ها (/announcements): لیست رسمی بیانیه‌ها، قطعی‌های آب/برق و
    فراخوان‌های شورا متصل به /api/v1/cms/announcements/ با فیلتر کپسولی.

۴. بخش رویدادها (Events)

  - گاه‌شمار رویدادها (/events): تفکیک سه‌بعدی رویدادها به ۳ بخش: در حال برگزاری
    (با پچ چشمک‌زن زنده)، رویدادهای آتی (گرید ۳ ستونه) و رویدادهای پایان‌یافته
    (با افکت سیاه و سفید).

۵. صفحه قوانین و مصوبات حقوقی (/about/legal)

  - برگه اسناد حقوقی: نمایش کارت‌های بنتو اسپلیت شامل شماره ابلاغیه، مرجع تصویب،
    متن مصوبه، پیش‌نمایش تصویر اسکن‌شده اصل نامه دادگستری، دکمه دانلود PDF و
    باکس تماس با دپارتمان حقوقی.

۶. رسانه و گالری (/media)

  - گالری تصاویر و ویدیوها: فیلتر کپسولی سوییچ بین عکس‌ها و فیلم‌ها، مدال پاپ‌آپ
    پخش ویدیو (Video Lightbox) و کارت‌های مینی‌مال.

🔐 پروژه مجزای پنل مدیریت (Admin Panel Site)

یک وب‌سایت مستقل و مجزا برای ادمین پورتال با قابلیت‌های زیر توسعه داده شده است:

1.  درگاه لاگین JWT: احراز هویت ادمین از طریق اندپوینت /api/v1/token/ و
    ذخیره‌سازی توکن در localStorage.
2.  مدیریت اخبار، اطلاعیه‌ها و رویدادها (Full CRUD):
      - جدول لیست مطالب (List View): با سرچ زنده در عناوین و دکمه‌های ویرایش و
        حذف.
      - فرم ثبت جدید و ویرایش (Create / Edit View): تولید خودکار و قفل‌شده‌ی
        اسلاگ (readOnly={true}) همزمان با تایپ عنوان برای جلوگیری از ارورهای
        دیتابیس.
3.  مدیریت دیدگاه‌ها (Comments Moderation): مشاهده نظرات ثبت‌شده کاربران، دکمه
    تایید دیدگاه (PATCH برای تغییر is_approved = true) و دکمه حذف نظرات اسپم.

⚙️ تنظیمات محیطی و عیب‌یابی (Environment & Setup)

۱. تنظیم فایل .env.local

در ریشه پروژه فایل .env.local را ایجاد کرده و آدرس بک‌اند را قرار دهید:

NEXT_PUBLIC_API_URL=http://10.176.114.121:8001/api/v1

۲. تنظیم فایل next.config.ts

جهت رفع خطای آی‌پی محلی (Private IP) و مجوز لود تصاویر از بک‌اند جنگو:

import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  env: {
    NEXT_PUBLIC_API_URL: process.env.NEXT_PUBLIC_API_URL || "http://10.176.114.121:8001/api/v1",
  },
  images: {
    dangerouslyAllowLocalIP: true, // رفع خطای private ip در Next.js 16
    unoptimized: true,
    remotePatterns: [
      { protocol: "https", hostname: "images.unsplash.com" },
      { protocol: "http", hostname: "10.176.114.121", port: "8001" },
    ],
  },
};

export default nextConfig;
